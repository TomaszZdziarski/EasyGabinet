III. APPOINTMENTS

A) bookings

 - patient/dentist (user) can book appointment by a chosen doctor.
 - Patient is restricted to establish up to 3 bookings which can last between 30min-1hour,to avoid malicious actions
 - a user is obligated to choose purpose of visit from drop-down list or fill the custom purpose field
 - a user cannot book a visit in the past
 - during booking overlapping is being checked to avoid double bookings for same day/hour,also crosschecking
   between patient users and dentist users
 - bookings can be made only during clinic's working time,between: 8:00 and 20:30
 - a user can cancel a booking, it gets "cancelled" status and patient user cannot further delete/edit this booking
 - booking is editable for a patient only before booking's start (time,date,reason and chosen dentist can be modified)

B) booking's status

 - Only dentists can change booking's status (function to change statuses) but only in own schedule(status "passed" is excluded from status options)
 - all possible time slots become "available" as default and get green color
 - when time of slot passes by and booking is not made, it becomes "passed" and it's greyed out of schedule
 - when booking is made(by patient or by dentist) a slot gets "booked" status and yellow color
 - patient can make up to 3 appointments(we count booking's statuses: "booked","did_not_occur","cancelled" as one used appointment)
 - when time of the booking passes, status of booking changes to "completed",gets blue color (this booking is considered
   to be successfully, so it doesn't count for max.3 bookings per patient)
 - to free patient's booking's pool all statuses can be cleared/changed by logged dentist/manager
 - when status of booking is being changed to "available", instance of appointment is being deleted from db,to free space and avoid double bookings
